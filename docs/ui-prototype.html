Gemini 1.5 sibuk (HTTP 429) • Otomatis dialihkan ke Groq Llama 3.3 70B tanpa jeda

Berdasarkan pembahasan pada Slide Bab 3: Sistem Terdistribusi, Teorema CAP (Brewer's Theorem) menyatakan bahwa sistem data terdistribusi tidak dapat menjamin ketiga karakteristik berikut secara bersamaan 1:

  • Consistency (Konsistensi): Setiap pembacaan menerima data tulis terbaru atau galat 1.
  • Availability (Ketersediaan): Setiap permintaan non-galat menerima respons tanpa jaminan data terbaru.
  • Partition Tolerance: Sistem tetap beroperasi meski terjadi partisi jaringan fisik 2.

Karena partisi jaringan tidak bisa dihindari, arsitektur sistem harus memilih antara konsistensi ketat (CP) atau ketersediaan tinggi (AP) saat terjadi pemisahan koneksi antar-node 2.
